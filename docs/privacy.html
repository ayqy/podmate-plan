Podmate 隐私说明

项目默认保存在本机；云端发送由你选择。

更新：2026-10-15

默认保存在此设备

文章原文、录音、视频、剪辑、练习反馈和已生成作品默认保存在此设备。本机录音、声音分析与本机配音可以不上传内容。Podmate没有自建的内容账户或自动跨设备同步。

由你选择的云端功能

使用阿里云生成问题、对谈、追问、配音、识别或姿态分析时，对应文字、选定原声或视频抽样帧会发送到你配置的模型服务。请求前的确认会说明范围与费用；仅查看项目、隐私说明或本机反馈不会发起这些模型请求。

你的API Key用于模型服务鉴权，保存在此设备Keychain，不加入项目、工程包或分享文件。服务提供方可按你账户适用的条款处理和保留请求，请在使用前了解其隐私与数据保留政策。

备份与分享

主动启用WebDAV时，原声或你单独启用的项目备份会发送到你指定的服务器；内容可能包含标题、问题卡、原件和记录。服务器账户、保留和删除由你与服务器提供方管理。

系统分享只发送你选择的作品或工程文件。工程包可能包含原始音视频和文字；分享前请核对内容、权利和接收方。

权限由你控制

麦克风用于主动录音、练习或语音剪辑；摄像头仅用于主动视频练习。文件通过系统选择器导入，不请求读取整份相册。你可在系统设置中关闭权限；已有本机原声仍可回听。

联网与使用记录

读取公开套餐策略、查看在线帮助或使用Apple购买相关功能会联网；提供方可能接收IP地址等网络基础信息。Podmate不接入广告、跨应用追踪或行为分析服务。

本机请求时长、用量和费用参考帮助核对消耗，不能代替服务商真实账单；主动核验的官方费用会另行标识。Apple交易和服务商账户分别由其平台处理。

成本页可由你主动读取OpenAI官方项目费用，或确认后修改该服务商项目的硬额度。这会向OpenAI发送项目ID、查询范围、额度设置和本次页面使用的Admin API Key；管理员密钥不写入项目、备份或日志，离开页面即清除。核验后的费用快照可在本机保存；分享或备份工程前请核对是否包含账务信息。

保留、删除与撤回

项目和原件保留到你主动删除。删除项目会清理其本机内容与明细，但为防止删除项目重置额度，不含内容的最小月度用量索引会保留。

删除API Key或关闭上传，可停止后续相关调用；不会删除已保存作品，也不会撤回已发送的请求。删除本机项目不删除WebDAV远端副本。对于服务商已收到的数据，请使用其账户管理或联系其支持；本机操作不能保证对方删除。

设备备份可能包含应用数据，其保留和删除由系统备份设置控制。请保管自己的工程文件和服务器备份。

联系与变更

Podmate由GitHub用户ayqy维护。可通过产品支持页面提交隐私、使用或第三方许可问题。请勿在公开问题中提供API Key、密码、私人原声或未经授权的内容。

本说明随数据流变化更新；涉及新的云端发送范围时仍会请求确认。
