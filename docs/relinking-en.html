Using these materials

Use a Mac matching the package architecture, Xcode 26.5, the corresponding Apple SDK and Python 3. Verify the package using its README before modifying LAME and running the build scripts.

Relinking invalidates the original App Store signature. Simulator packages use a temporary local signature. Device packages require your own development signing identity and provisioning profile. Platform installation and StoreKit requirements still apply.
