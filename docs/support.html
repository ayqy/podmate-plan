Podmate 产品支持

Podmate 用于访谈、文章播客与口才练习。此页面提供使用、隐私和第三方许可支持；应用上架状态以 App Store 为准。

联系支持

产品使用与隐私问题请发送至 nwujiajie@163.com。请勿发送密码、API Key或私人原声。

提交问题

通过 公开问题页面联系维护者 ayqy。请提供应用版本、设备与系统版本、操作步骤和不含隐私的错误说明。

请勿提交 API Key、密码、私人原声、整份工程或未经授权内容。公开问题任何人可见；截图请先移除个人信息。

隐私与原件

项目默认保存在本机；可选上传和远端副本边界见隐私说明。不要为了排查问题删除唯一原件或备份。

第三方许可与源码

MP3 编码使用 LAME。许可与上游授权全文、当前集成的 LAME 库源码及源码摘要清单可直接下载。

下载对应版本的 LAME 替换重链接材料，包括库源码、许可、应用对象、资源和构建说明。
